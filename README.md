# Student Performance Data Analysis

A beginner data-analysis project using a small sample dataset to practise Python, pandas, and matplotlib.

## What it does
- Loads student marks from `students.csv`
- Calculates total and average marks
- Prints the top-performing students
- Creates a bar chart of average marks

## Setup
```bash
python -m pip install pandas matplotlib
python analyze_performance.py
```

## Dataset
`students.csv` is a small fictional sample created for learning. Do not replace it with identifiable student records.
